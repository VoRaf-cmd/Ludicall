# Ludicall

Aplicativo desktop para acessar o Ludicall no Windows.

## Baixar

Acesse [Releases](https://github.com/VoRaf-cmd/Ludicall/releases) e baixe o instalador Windows. O instalador inclui os arquivos do Electron e não baixa o pacote durante a instalação. O app precisa de internet para acessar o serviço online.
